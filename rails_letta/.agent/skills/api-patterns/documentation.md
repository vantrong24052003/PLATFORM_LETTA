# Các Nguyên tắc Tài liệu API (API Documentation Principles)

> Tài liệu tốt = lập trình viên hạnh phúc = API được sử dụng rộng rãi.

## Các yếu tố Thiết yếu của OpenAPI/Swagger

```
Nên bao gồm:
├── Tất cả các endpoint kèm ví dụ
├── Schema của Request/Response
├── Các yêu cầu về xác thực (Authentication)
├── Định dạng phản hồi lỗi
└── Thông tin về giới hạn tốc độ (Rate limiting)
```

## Một Tài liệu tốt cần có

```
Các thành phần chính:
├── Hướng dẫn Bắt đầu nhanh (Quick start)
├── Hướng dẫn Xác thực
├── Tham chiếu API đầy đủ
├── Hướng dẫn xử lý lỗi
├── Ví dụ code (nhiều ngôn ngữ)
└── Nhật ký thay đổi (Changelog)
```
