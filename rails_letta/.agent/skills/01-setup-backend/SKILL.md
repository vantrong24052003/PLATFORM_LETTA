# Setup Backend Skill (Rails)

## Overview
This skill guides you through **Phase 1** of the `rails_letta` project: Building the Bot Template System backend using **Ruby on Rails**.

## How It Works

### Step 1: Generate Resources (Scaffold)
We use `rails generate resource` to create Model, Migration, Controller, and Routes in one go.

- [ ] **Generate Bot Template**:
    ```bash
    rails generate resource Letta::BotTemplate \
      organization_id:string:index \
      name:string \
      greeting:text \
      status:string \
      system_prompt:text \
      tools:jsonb \
      source_ids:jsonb \
      theme_config:jsonb \
      --no-test-framework
    ```

- [ ] **Generate Agent Mapping**:
    ```bash
    rails generate resource Letta::AgentMapping \
      organization_id:string:index \
      bot_template:references \
      customer_user_id:string:index \
      letta_agent_id:string:index \
      --no-test-framework
    ```

- [ ] **Update Migrations**:
    - Ensure `id` fields are UUIDs if using UUIDs (default in Rails 8 if configured).
    - Add unique index to `agent_mappings`: `add_index :letta_agent_mappings, [:organization_id, :bot_template_id, :customer_user_id], unique: true`
    - Run: `rails db:migrate`

### Step 2: Implement Logic

#### Services (`app/services/letta/bot_service.rb`)
- [ ] Implement `Letta::BotService` to handle complex logic (e.g., calling LeTTa Engine).

#### Controllers (`app/controllers/letta/bot_templates_controller.rb`)
- [ ] Implement `index`, `show`, `create`, `update`, `destroy`.
- [ ] **Important**: Verify `organization_id` in headers/params for every request.

#### Controllers (`app/controllers/letta/agent_mappings_controller.rb`)
- [ ] This controller was generated by the resource generator.
- [ ] Implement `create` action to handle "Get or Create Agent" logic.

#### Routes (`config/routes.rb`)
Update the routes to nest `agent_mappings` under `bot_templates`:

```ruby
namespace :letta do
  resources :bot_templates do
    resources :agent_mappings, only: [:create]
  end
  # ... messages/streaming routes ...
end
```

## Best Practices
- **ActiveRecord**: Use ActiveRecord methods (`find_by`, `create!`) instead of raw SQL.
- **Service Objects**: Keep business logic (like calling the external AI service) inside the Service.
- **Strong Parameters**: Always check params in the controller.
